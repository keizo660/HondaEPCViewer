# Honda EPC Viewer

Hondaの電子パーツカタログ（CD-ROM版）のデータを読み込み、車両情報・部品番号・部品名・価格・図面を閲覧するための非公式ビューアです。
Honda純正の閲覧ソフトを置き換えるものではなく、個人による部品確認や資料参照を補助する目的のツールになります。

## 主な機能

- データベース内の車名・形式・フレーム番号・仕様の選択
- 部品番号、部品名、価格の表示
- 部品一覧と図面の連動
- 図面上の見出し番号と部品一覧の対応表示
- 部品番号または部品名からの逆引き検索
- 検索結果から該当する車両・図面の確認

## 動作環境

- Windows 11
- Python 3.10以降を推奨
- Pillow

本ソフトウェアの動作確認は、2005年4月版のHonda電子パーツカタログのみで行っています。
それ以外の時期・バージョンの電子パーツカタログについては、データ構造や収録内容の違いにより、正常に動作しない可能性があります。

## セットアップ

1. WindowsにPythonをインストールします。
2. このリポジトリのファイルを同じフォルダーに置きます。
3. コマンドプロンプトまたはPowerShellで、そのフォルダーを開きます。
4. 次のコマンドで必要なライブラリをインストールします。

```powershell
py -m pip install -r requirements.txt
```

5. `data` フォルダーの中にカタログ用のフォルダーを作成し、CD-ROMの中身を全てコピーします。
   ※カタログフォルダーの名前は任意ですが、半角18文字を超える分は表示されません。
   ※フォルダー名を使い分けることで、複数のカタログを切り替えて使うことができます。

6. `HondaEPCViewer.py` を実行します。

```powershell
py HondaEPCViewer.py
```

## アプリの使用方法

### 起動

セットアップ完了後、アプリのフォルダーで次のコマンドを実行します。

```powershell
py HondaEPCViewer.py
```

### 車両と部品図の表示

1. **カタログ**から、`Data` フォルダーに配置したカタログを選択します。
2. **車名**から調べたい車両を選択します。
3. **形式**、**フレームNo.**、**タイプ**、**オプション**を順に選択し、対象車両の条件を指定します。選択肢はカタログに収録されている情報に応じて表示されます。
4. **グループ**を選択します。
5. 左側の**ブロック**一覧から見たい項目を選択すると、右側に対応するイラストと部品一覧が表示されます。

### イラストと部品一覧の操作

- イラスト上でマウスホイールを操作すると拡大・縮小できます。
- イラストを拡大した状態でドラッグすると、表示位置を移動できます。
- イラスト上の見出し番号をダブルクリックすると、部品一覧の対応する行が選択されます。
- 部品一覧の行をダブルクリックすると、イラスト上の対応する見出し番号が強調表示されます。
- 部品番号または部品名の上で右クリックし、**逆引き検索**を選ぶと、その文字列を検索欄に入力した状態で逆引き検索画面が開きます。
- イラストと部品一覧の境界をドラッグすると、それぞれの表示領域の大きさを調整できます。

### 逆引き検索

1. メイン画面上部の**逆引き検索**をクリックします。
2. 検索欄に部品番号または部品名を入力し、**検索**をクリックします。Enterキーでも検索できます。
3. 検索結果の行を選択すると、該当する図面が下部に表示されます。
4. 検索結果をダブルクリックするか、選択した状態でEnterキーを押すと、その車両・条件・図面をメイン画面に反映します。

※逆引き検索の範囲は、現在選択されているカタログ内のみです。

## Honda EPCデータの配置

Honda EPCのカタログデータは、このソフトウェアの配布物には含まれていません。

利用者自身が適法に使用できるデータを、次のような構成で `Data` フォルダーに配置してください。

```text
HondaEPCViewer/
├─ HondaEPCViewer.py
├─ epc_cache.py
├─ requirements.txt
└─ Data/
   └─ (カタログ名)/
      ├─ TSMIR.CD
      ├─ KRHHKI.CD
      ├─ KSRBHMH.CD
      ├─ SYSBMST.CD
      └─ 11SA511/
         ├─ GRPTBL.CD
         ├─ BLKTYTBL.CD
         ├─ PLMST.CD
         └─ （図面などの関連ファイル）
```

上記は配置イメージです。実際のCD内のフォルダー構成を保って配置してください。データベース名のフォルダーには、共通管理ファイルと車種データのフォルダーをまとめて入れます。

初回起動時または元データの更新時には、検索用SQLiteキャッシュが `Cache` フォルダーに自動生成されます。図面の変換画像は `image_cache` フォルダーに保存されます。これらは再生成可能な作業用ファイルであり、GitHubへの登録対象ではありません。
