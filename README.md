# Honda EPC Viewer

Hondaの旧型電子パーツカタログのデータを読み込み、車両情報・部品番号・部品名・価格・図面を閲覧するための非公式ビューアです。

Honda純正の閲覧ソフトを置き換えるものではなく、個人による部品確認や資料参照を補助する目的のツールです。

## 主な機能

- データベース内の車名・形式・フレーム番号・仕様の選択
- 部品番号、部品名、価格の表示
- 部品一覧と図面の連動
- 図面上の見出し番号と部品一覧の対応表示
- 部品番号または部品名からの逆引き検索
- 検索結果から該当する車両・図面の確認

## 動作環境

- Windows 11
- Python 3.10以降を推奨
- Pillow

本ソフトウェアの動作確認は、**2005年4月版のHonda電子パーツカタログ**のみで行っています。それ以外の時期・バージョンの電子パーツカタログについては、データ構造や収録内容の違いにより、正常に動作しない可能性があります。2005年4月版以外のバージョンについては、動作を保証していません。

## セットアップ

1. WindowsにPythonをインストールします。
2. このリポジトリのファイルを同じフォルダーに置きます。
3. コマンドプロンプトまたはPowerShellで、そのフォルダーを開きます。
4. 次のコマンドで必要なライブラリをインストールします。

```powershell
py -m pip install -r requirements.txt
```

5. `HondaEPCViewer.py` を実行します。

```powershell
py HondaEPCViewer.py
```

## Honda EPCデータの配置

Honda EPCのカタログデータは、このソフトウェアの配布物には含まれていません。

利用者自身が適法に使用できるデータを、次のような構成で `Data` フォルダーに配置してください。

```text
HondaEPCViewer/
├─ HondaEPCViewer.py
├─ epc_cache.py
├─ requirements.txt
└─ Data/
   └─ データベース名/
      ├─ TSMIR.CD
      ├─ KRHHKI.CD
      ├─ KSRBHMH.CD
      ├─ SYSBMST.CD
      └─ 11SA511/
         ├─ GRPTBL.CD
         ├─ BLKTYTBL.CD
         ├─ PLMST.CD
         └─ （図面などの関連ファイル）
```

上記は配置イメージです。実際のCD内のフォルダー構成を保って配置してください。データベース名のフォルダーには、共通管理ファイルと車種データのフォルダーをまとめて入れます。

初回起動時または元データの更新時には、検索用SQLiteキャッシュが `Cache` フォルダーに自動生成されます。図面の変換画像は `image_cache` フォルダーに保存されます。これらは再生成可能な作業用ファイルであり、GitHubへの登録対象ではありません。
